=========================================
   Project Props 3.1 Community Edition
=========================================

Thank you for downloading the Community Edition of Project Props!  
This mod brings a massive rework of world props for GTA: San Andreas,  
improving immersion, fixing logical issues, and making the game world feel alive.  

-----------------------------------------
 Requirements
-----------------------------------------
To run this mod properly, you need the following:

- Essentials Pack
- Open Limit Adjuster
- Fastman Limit Adjuster
- Fastloader

Make sure all requirements are installed before launching the game.
All downloads links are listed here: https://github.com/user-grinch/Project-Props

-----------------------------------------
 Installation
-----------------------------------------
1. Extract the archive.
2. Place the folder **"Project Props 3.1 Community"** into your `modloader` directory.
3. Launch the game and enjoy!
